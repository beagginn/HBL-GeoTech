Site institucional da **HBL GeoTech**, desenvolvido para apresentar a empresa, seus serviços e seus diferenciais.

## Tecnologias

As tecnologias utilizadas devem corresponder à implementação atual do projeto. A estrutura prevista inclui:

- HTML5
- CSS3
- Python
- Django

## Como executar o projeto

### 1. Crie um ambiente virtual

```bash
python3 -m venv venv
```

### 2. Ative o ambiente virtual

**macOS / Linux:**

```bash
source venv/bin/activate
```

**Windows:**

```bash
venv\Scripts\activate
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

### 4. Execute as migrações

```bash
python3 manage.py migrate
```

### 5. Inicie o servidor

```bash
python3 manage.py runserver
```

Acesse o endereço abaixo no navegador:

http://127.0.0.1:8000/
